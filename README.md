# 夜游神 · 山河漫游 | NIGHT ROAMER

> 白天归生活，夜里归自己。三千山河，随便逛，不赶时间。

一个纯前端的 3D 中国山河漫游网站。无需后端、无需数据库，打开浏览器即可夜游全国 34 省级行政区的代表性景点。所有数据仅存储在你自己的浏览器 localStorage 中。

## 在线体验

**https://2421755157.github.io/xiaodong-yyds/**

手机和电脑均可访问。电脑端使用 WASD + 鼠标操控，手机端使用虚拟摇杆 + 滑动环视。

## 功能一览

### 3D 第一人称漫游
- 基于 Three.js 的程序化 3D 场景生成（无需加载外部模型）
- 覆盖全国 34 省、数百个城市、上千个景点
- 四种时辰主题：晨曦 / 白昼 / 黄昏 / 深夜，实时切换光影氛围
- 碰撞检测、地面贴合、跳跃、疾走
- 标志地点热点解说 + 真实景点图片（Wikimedia Commons）

### 今日一签（灵签办事处）
- 每日一签，签文等级（上上签/上签/中签）+ 编号 + 宜忌标签
- 20 条原创签文，温暖、抽象、略带荒诞
- 同一天结果固定，不重复不刷新

### 碎碎平安（情绪粉碎局）
- 写下烦恼，一键粉碎，不保存、不上传、不留证据
- 累计粉碎计数 + 随机碎后寄语
- CSS 粉碎动画，仪式感拉满

### 精神状态鉴定（SBTI 体系）
- 基于足迹文本的情绪分析引擎（4 维度 × 16 型人格）
- 无足迹时自动触发快速问卷（4 题即出结果）
- Canvas 绘制 1080×1350 鉴定卡，可下载分享
- 仙气值 / 癫值 / emo浓度 / 生命力 四维数据条

### 足迹系统
- 在 3D 场景中留下带心情、评分、文字的足迹
- 足迹时间线回顾
- 成就称号解锁（初次踏入夜色 → 夜游神的常住人口）

### 个人档案
- 自定义称呼、签名、想去的城市、夜游心情
- 漫游数据统计（足迹数、到访景点、粉碎烦恼数）

## 技术栈

| 类别 | 技术 |
|------|------|
| 3D 渲染 | Three.js 0.164.1 + EffectComposer + UnrealBloom |
| 模块系统 | ES Modules + Import Map（CDN 加载） |
| 数据存储 | localStorage（纯前端，无后端） |
| 图片来源 | Wikimedia Commons API |
| 部署 | GitHub Pages（静态托管） |
| 本地开发 | Node.js 静态服务器（server.cjs） |

## 项目结构

```
├── index.html          # 主页面（所有弹窗和区块）
├── server.cjs          # 本地开发服务器（端口 8765）
├── styles/
│   └── main.css        # 全部样式
├── js/
│   ├── app.js          # 主逻辑（导航、事件、UI）
│   ├── roam.js         # 第一人称控制器（WASD + 触摸）
│   ├── scenes.js       # 程序化 3D 场景生成
│   ├── china-data.js   # 全国省市景点数据
│   ├── mood.js         # SBTI 情绪分析 + Canvas 卡片
│   ├── lexicon.js      # 文案词库（签文、判词、热梗）
│   ├── store.js        # localStorage 数据层
│   └── spot-images.js  # 景点真实图片映射
└── README.md
```

## 本地运行

```bash
# 需要 Node.js
node server.cjs
# 打开 http://localhost:8765/
```

> 注意：由于使用 ES Modules + Import Map，不能直接双击 index.html 打开，必须通过 HTTP 服务器访问。

## 操作说明

### 电脑端
- **W A S D** — 移动
- **鼠标** — 环视（点击画面锁定指针）
- **Shift** — 疾走
- **Space** — 跳跃
- **E** — 留下足迹
- **G** — 查看标志地点解说
- **F** — 心情鉴定
- **Esc** — 释放鼠标

### 手机端
- **左侧摇杆** — 移动
- **右侧滑动** — 环视
- **足迹按钮** — 留下足迹
- **解说按钮** — 查看地点解说
